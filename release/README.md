# Perks Reminder AMEX reader release

This directory is generated by `npm run build:amex-reader-extension` and contains upload-ready artifacts for the Chrome Web Store and Greasy Fork. It is intentionally not published by this repository.

The reader performs no automatic scan. It reads only named first-party American Express endpoints after a manual action, stores normalized observations locally, and offers an optional reviewed handoff to Perks Reminder. Do not enable the Chrome and Greasy Fork editions together.
